# Joalda Fashion

A sustainable, cultural fashion e-commerce application.

## Tech Stack

*   **Runtime**: Bun
*   **Frontend**: React, React Router
*   **Backend**: Bun.serve, SQLite
*   **Styling**: Custom CSS (inspired by nature)

## Setup

1.  Install dependencies:
    ```bash
    bun install
    ```

2.  Build the frontend:
    ```bash
    bun run build
    ```

3.  Start the server:
    ```bash
    bun start
    ```

4.  Open http://localhost:3000

## Features

*   **Shop**: Browse products with categories.
*   **Cart**: Add products, manage quantities.
*   **Admin Panel**: Add, Edit, Delete products (Login: `admin` / `admin123`).
*   **Authentication**: User login and signup.
